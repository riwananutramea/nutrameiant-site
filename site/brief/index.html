The Tuesday brief

What is in each issue

Rule changes
New and amended circulars, label requirements and import conditions, each with the issuing authority, the source document and the date it takes effect
Registration movement
Categories where dossier processing has visibly sped up or slowed down, and what changed
Enforcement
Recalls, border rejections and public warnings, with the stated reason
Trade
Distribution agreements, launches and facility approvals that are public record
One read
A single longer piece when something deserves more than a paragraph

How an entry gets in

  • Primary source first

    An entry starts from the authority's own publication, not from a secondary report about it. The source is named in the entry.

  • Dated, not undated

    Publication date and effective date are separate fields. Where an authority gives a transition period, the end of that period is stated.

  • Corrections stay visible

    When an entry is wrong it is corrected in the record and the correction is noted in the following issue. Nothing is quietly rewritten.
