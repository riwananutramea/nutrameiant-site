# Putting the design rules into the WordPress theme

This folder holds one generated file, `nutramea-design.php`. It carries two things:

1. the colours, spacing and type scale from `site/assets/tokens.css` and `site/assets/site.css`
2. the `/wp-json/nutramea/v1/subscribe` route that the brief signup form posts to

It is generated by `npm run build`. Do not edit it here and do not edit it in WordPress,
because the next build overwrites it. Change the stylesheets or
`src/wordpress/nutramea-design.php.tpl` instead.

## Installing it, once

1. Open `wordpress/nutramea-design.php` in this repository and copy everything from the
   line `if ( ! defined( 'ABSPATH' ) ) {` to the end of the file. Leave the `<?php` line
   and the comment block behind.
2. In WordPress, go to Appearance, then Theme File Editor, and open `functions.php` in
   the `nutramea-theme` theme.
3. Scroll to the very bottom and paste on a new line.
4. Press Update File.

If the page returns an error after saving, remove what you pasted and the site comes
back. Nothing else in the theme is touched.

### A safer route, if you have file access

Upload `nutramea-design.php` into the theme folder and add one line at the bottom of
`functions.php` instead:

```php
require_once get_stylesheet_directory() . '/nutramea-design.php';
```

Then a rebuild is a file replacement rather than a copy and paste.

## Updating it later

Run `npm run build`, open the regenerated `wordpress/nutramea-design.php`, and repeat the
paste. The styles are versioned by a hash of their own content, so browsers pick up a
change immediately and keep using the cache when nothing changed.

## The subscriber list

Addresses go into the `nutramea_subscribers` WordPress option, and the site admin address
gets an email for each new one.

To download the list as a spreadsheet, sign in to WordPress as an administrator and visit:

```
/wp-admin/admin-post.php?action=nutramea_export_subscribers
```

That returns a CSV of every address with the date it was added. Only administrators can
open it.

An address can try to subscribe five times an hour. Beyond that the route answers 429 and
stores nothing, so the form cannot be used to fill the list with junk.

## What this file does not do

It does not send the brief. It collects addresses and hands you a CSV. Sending goes
through whatever mail tool you choose, and that choice is still open.

It also does not restyle theme markup that uses its own class names. The tokens are
available to every page, but a template that hardcodes a colour keeps that colour until
the template is changed to use `var(--accent)` and the rest.
